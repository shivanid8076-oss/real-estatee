# Bala Ji Property | Luxury Homes Built on Trust

A premium, interactive real estate landing page designed for luxury property listings and plot management.

## 🚀 Features

- **High-End UI/UX**: Dark theme with gold accents, custom glassmorphism effects, and modern typography.
- **Dynamic Animations**: Powered by GSAP and ScrollTrigger for a smooth, premium feel.
- **Interactive Property Portfolio**:
  - Add, Edit, and Delete property listings directly via the browser.
  - Data persistence using `localStorage`.
  - Image preview, price formatting, and location tagging.
- **Modern Search Filters**: Filter properties by type and interest.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **WhatsApp Integration**: Direct enquiry buttons for quick client-to-dealer interaction.

## 🛠️ Technologies Used

- **Core**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Animations**: [GSAP](https://gsap.com/) & ScrollTrigger
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Typography**: Playfair Display, Jost, DM Serif Display (via Google Fonts)

## 📂 Project Structure

- `prestige_estates_landing.html`: The main landing page with all logic and styles.
- `properties.html`: Dedicated properties listing page (complementary).

## 🖥️ Getting Started

To run this project locally:

1. Clone or download the repository.
2. Open `prestige_estates_landing.html` directly in your browser.
   - *Alternatively, run a local server for the best experience:*
     ```bash
     npx serve .
     ```
3. Visit `http://localhost:3000/prestige_estates_landing.html`.

## 📌 Usage - My Plots Section

You can manage your own property listings locally in the browser:
1. Scroll down to the **"My Plots & Properties"** section.
2. Click **"Add New Plot"** to open the management modal.
3. Fill in the details (Name, Price, Location, Image URL, etc.) and click **"Save & Publish"**.
4. Use the **Edit** (pencil) or **Delete** (trash) icons on each card to manage existing entries.
